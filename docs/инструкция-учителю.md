# Инструкция для учителя: как посмотреть результаты ЕНТ

## 1. Регистрация

Откройте https://ent.pmci.kz → **«Регистрация»**.

Выберите вкладку **«Преподаватель»**. Заполните:

- Фамилия и Имя;
- Логин (латиницей, например `arman_k`);
- Email;
- Пароль (минимум 8 символов);
- **Инвайт-код центра** — его выдаёт администратор. Без кода регистрация не пройдёт.

Нажмите **«Зарегистрироваться»**. После этого откроется кабинет учителя.

Если инвайт-кода нет — напишите администратору.

## 2. Вход

Зайдите на https://ent.pmci.kz → **«Войти по логину и паролю»** → введите свой логин и пароль.

Кнопка Telegram — для учеников, учителям она не нужна.

## 3. Где что находится

В меню слева (на телефоне — внизу):

- **«Ученики и группы»** — список учеников, их классы, треки, группы и средний балл.
- **«Результаты»** — все пройденные тесты с баллами.
- **«Пробные тесты»** — кто сдал, кто не сдал пробники по группам.
- **«Аналитика»** — графики и общая статистика.

## 4. Посмотреть результаты ЕНТ

Нажмите **«Результаты»**.

Над таблицей есть фильтры:

- **Предмет** — выберите нужный вариант, например «Пробные от INTELLECT · ЕНТ 01»;
- **Группа** — чтобы посмотреть только свою группу;
- **С** и **По** — диапазон дат;
- **Ученик** — можно найти конкретного человека по имени.

В таблице видно: ученик, предмет, дата, процент, группа.

## 5. Вытащить ответы ученика

Нажмите на строку с нужным тестом — откроется страница результата.

Там видно:

- процент, сколько правильных и неправильных;
- **«Разбор ответов»** — каждый вопрос по порядку:
  - зелёная галочка — ученик ответил правильно;
  - красный крестик — ответ ученика и рядом **правильный ответ**;
  - если вопрос с картинкой — она тоже отображается.

Чтобы сохранить ответы:

- нажмите кнопку **PDF** вверху справа — откроется печать;
- выберите **«Сохранить как PDF»** — файл сохранится на компьютере.

Кнопка **«К списку тестов»** внизу — вернуться назад.

## 6. Если нужно посмотреть успеваемость по группе

Зайдите **«Пробные тесты»** → вкладка «Доступ и статистика» → выберите группу и пробный вариант.

Там сразу видно: всего в группе, сдали, не сдали, у кого открыт доступ вручную. Если кто-то не сдал — можно нажать «Открыть доступ» и пустить его доделать.

## 7. В конце

- Проверьте, что все ученики вашей группы сдали (или посмотрите, кто не сдал).
- Сохраните PDF с разбором ответов тем, кому нужно разобрать ошибки.
- Если ученик не сдал, а срок прошёл — откройте ему доступ в разделе «Пробные тесты».
- Если что-то не работает — сделайте скриншот и напишите администратору.
